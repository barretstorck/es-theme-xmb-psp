## Task 1: Square cross anchor

Implements spec Change 1. Moves the selected-system anchor up so the empty space in the screen's top-left corner is a true pixel-square: the selected icon's top-left corner equidistant (in pixels) from the top and left edges. `crossX` stays; `crossY` is tuned.

**Files:**
- Modify: `_inc/common.xml` (`crossY` value)
- Modify: `_inc/system.xml` (system carousel `pos.y`)

- [ ] **Step 1: Measure the current anchor on-device**

Deploy the current theme and screenshot the system view:
```bash
./scripts/deploy.sh push
```
Read `.dev/last-shot.png`; if ES is on the system carousel, `./scripts/ui.sh reload-theme`, then `./scripts/deploy.sh shot` and Read `.dev/last-shot.png`.

On the 1024x768 screenshot, measure the **selected (enlarged) system icon's top-left corner**:
- `L` = pixels from the screen's LEFT edge to the icon's left edge.
- `T` = pixels from the screen's TOP edge to the icon's top edge.

`L` is the target — the horizontal position is already correct. The goal is `T == L`.

- [ ] **Step 2: Compute the new `crossY`**

The icon moves vertically with `crossY` one-to-one. To move the icon's top edge from `T` to `L` pixels:

```
new_crossY = 0.33 + (L - T) / 768
```

(Current `crossY` is `0.33`. If the icon sits too low, `T > L`, so `new_crossY` is smaller — the icon moves up.) Round to 3 decimals.

- [ ] **Step 3: Update `_inc/common.xml`**

Change the `crossY` variable:
```xml
    <crossY>0.33</crossY>
```
to the computed value, e.g.:
```xml
    <crossY>NEW_CROSSY</crossY>
```

- [ ] **Step 4: Update the system carousel `pos.y` in `_inc/system.xml`**

The carousel container's vertical center must stay at `crossY`. The container is `<size>1.6 0.30</size>`, so `pos.y = crossY - 0.15`. The current carousel line is:
```xml
      <pos>-0.56 0.18</pos>
```
Change the y value to `new_crossY - 0.15`:
```xml
      <pos>-0.56 NEW_POSY</pos>
```
Update the adjacent comment's `y=0.18` / `centerline y=0.33` figures to match.

- [ ] **Step 5: Validate XML**

```bash
python3 -c "import xml.dom.minidom,sys; xml.dom.minidom.parse(sys.argv[1])" _inc/common.xml
python3 -c "import xml.dom.minidom,sys; xml.dom.minidom.parse(sys.argv[1])" _inc/system.xml
```
Expected: no output, exit 0, for each.

- [ ] **Step 6: Deploy, verify, iterate**

Deploy and reload (see Operating notes), screenshot the system view, Read it. Re-measure `T` and `L`. If `|T - L|` is more than ~5 px, the rendered-size estimate was slightly off — repeat Steps 2-6 with the new measurement. Iterate until the icon's top-left corner is visibly equidistant from the top and left edges (a square of empty space).

- [ ] **Step 7: Commit**

```bash
git add _inc/common.xml _inc/system.xml
git commit -m "$(cat <<'EOF'
v0.6 task 1: square cross anchor — crossY tuned so top-left space is square

The selected system icon's top-left corner now sits the same pixel
distance from the screen's top edge as from its left edge. crossX is
unchanged; crossY moved up and the system carousel pos.y recomputed
(pos.y = crossY - 0.15). Final value set by on-device measurement.
```
